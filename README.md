## 🌟 About This Project

This repository contains the source code for my personal portfolio website, built with a bold and striking **Neobrutalism** aesthetic. It serves as a central hub for my full-stack web applications, AI-driven projects, open-source work, and cloud certifications (like Microsoft Azure AZ-900 & Oracle Cloud).

### 🎨 Design Aesthetic
The site is built to be visually distinct using Neobrutalism design principles:
- **Harsh Shadows & Borders:** Thick outlines and sharp drop shadows (`4px 4px 0px #000`) for a tactile, retro-web feel.
- **Vibrant Accent Colors:** Eye-catching primary (`#FF6B35`) and secondary (`#FFD60A`) colors.
- **Dynamic Themes:** Flawless light and dark mode toggles with distinct color palettes.
- **Micro-Animations:** Clean typewriter effects, hover interactions, and smooth scroll reveals to make the interface feel alive.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have Node.js and npm (or Yarn/pnpm) installed on your machine.

### Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/himanshulokhande26/Portfolio.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Portfolio
   ```
3. Install the NPM packages:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to `http://localhost:3000` to see the site in action!
